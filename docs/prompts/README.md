## What the repository does hold for Steps 2 to 7

- `CLAUDE.md` holds the rules and roadmap that the prompts set out. It is not a prompt.
- `docs/reviews/log.md` holds the review records for each chapter pass.
- `docs/reviews/part-a-diff.md` holds the itemised change list for Step 4 Part A.

## The Step 5 close-out and Parts 0 to E

The request that approved the Step 5 close-out and the Step 6 and 7 work (Parts 0, A, B, C, D and E) was
written in plan mode. The plan file is outside the repository, and the request itself is not in `docs/`.
It is not saved here.

## Where the rest might be

The session transcript on the machine that ran the work holds the messages as they were sent. It is outside
the repository and outside `docs/`, so it was not used for this index. Recovering from it would need the
owner's go-ahead, and any credential or private link in it would have to be redacted before it is saved here.
